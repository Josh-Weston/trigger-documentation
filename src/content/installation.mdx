# Installation

**Trigger** does not have any dependencies, so installation into your project is simple and lightweight:

```bash
npm i @jweston/trigger
```

Trigger uses _semver_ naming conventions, so you can install a specific version if needed:

```bash
npm i @jweston/trigger@0.22.0
```

You can review the entire [npmjs version history](https://www.npmjs.com/package/@jweston/trigger?activeTab=versions) for **Trigger**

<mark>
  **Note:** It is recommended that you use **Trigger** with **TypeScript** for
  an optimal developer experience
</mark>
